## Other ways to help

Financial support is never required. You can also help SentryNet by:

- Starring the repository so more self-hosters can find it.
- Reporting reproducible bugs through GitHub Issues.
- Suggesting useful monitoring and security improvements.
- Improving documentation or contributing tested fixes.

Thank you for supporting independent, self-hosted security software.
